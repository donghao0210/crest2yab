# Agent instructions

If a user asks you to help migrate from Crest to Yab using this repo, follow
[`skills/crest2yab/SKILL.md`](skills/crest2yab/SKILL.md) exactly, including its rules on never reading
cookie values, getting confirmation before `write-spaces`, and letting the user quit the browsers
and answer the Keychain prompts themselves. The script is `crest2yab.py` (a link to
`skills/crest2yab/scripts/crest2yab.py`).
